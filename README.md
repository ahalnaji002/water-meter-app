# حاسبة توزيع المياه

## Project Overview

مشروع موحّد يحتوي على تطبيق ويب مبني بـReact وتطبيق موبايل مبني بـReact Native وExpo. يشترك التطبيقان في حزمة TypeScript واحدة للحسابات والبيانات الأولية، ما يضمن تطابق النتائج على الويب وAndroid وiOS.

يعتمد الحساب على استهلاك الكهرباء وسعر الكيلو والخصم لتحديد المبلغ النهائي، ثم يوزّع المبلغ على المشتركين حسب استهلاك المياه. تبدأ البيانات من كشف 31-8-2026: قراءة الكهرباء السابقة 3369 وأسماء وقراءات المياه السابقة للـ26 مشتركًا.

## Features

- إدخال قراءة الكهرباء الحالية، الخصم، وسعر كيلو الكهرباء القابل للتعديل.
- إدخال قراءة المياه الحالية فقط لكل مشترك.
- حساب استهلاك الكهرباء، المبلغ بعد الخصم، مجموع أكواب المياه، سعر الكوب، وحصة كل مشترك.
- حفظ الدورة وترحيل القراءات الحالية تلقائيًا لتصبح السابقة للدورة القادمة.
- سجل محلي للدورات السابقة.
- تطبيق ويب متجاوب يدعم الطباعة.
- تطبيق موبايل أصلي لـAndroid وiOS عبر Expo.
- منطق حساب موحّد ومتحقق بالأنواع داخل `packages/core`.

## Setup

يتطلب المشروع Node.js 22.12 أو أحدث.

```bash
npm install
```

تشغيل تطبيق الويب:

```bash
npm run web
```

إنشاء نسخة إنتاجية من الويب:

```bash
npm run web:build
```

تشغيل تطبيق الموبايل وفتح رمز QR في Expo Go:

```bash
npm run mobile
```

أو تشغيله مباشرة على Android:

```bash
npm run mobile:android
```

على macOS مع Xcode يمكن تشغيل iOS باستخدام:

```bash
npm run mobile:ios
```

لفحص TypeScript في جميع الحزم:

```bash
npm run typecheck
```

بيانات الويب محفوظة في `localStorage` وبيانات الموبايل في `AsyncStorage`. البيانات محلية على كل جهاز ولا تتم مزامنتها حاليًا.

## Dependencies

- React 19.1 وReact DOM لتطبيق الويب والموبايل.
- Vite 8 لتطوير وبناء تطبيق الويب.
- React Native 0.81.5 وExpo SDK 54 المتوافق مع نسخة Expo Go في المتاجر لتطبيق الموبايل.
- AsyncStorage لحفظ بيانات تطبيق الموبايل محليًا.
- TypeScript 5.9 المتوافق مع Expo SDK 54 وحزمة `@water-meter/core` المشتركة لمنطق الحساب.
